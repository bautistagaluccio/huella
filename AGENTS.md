- Hosted on Vercel (nitro `vercel` preset in vite.config.ts); this repo, not Lovable, is the source of truth — why: the project was migrated off Lovable.
- Images live in src/assets and are imported as files — why: Lovable's `.asset.json` pointers only resolve on Lovable hosting.
- Admin area is a single client-only route (/admin-huella) using the browser client; access is enforced by RLS via has_role(admin) on user_roles — why: no server functions needed, DB is the security boundary.
- Sport availability pages use one dynamic /sports/$sport route, while individual scheduled experiences keep dedicated detail routes — why: sport listings stay consistent without duplicating page structure.
- Featured departures render from browser-safe structured calendar data sorted by departure month then starting day — why: multiple departures in one month remain chronological and testable.
- The Bali retreat (May 15–21) has a dedicated route rendering BaliRetreatPage with its dates passed in (full-bleed hero, facts bar, sticky section nav, brand-palette bands); its text and partner logos live in src/lib/bali-retreat-content.ts and listings come from src/lib/departures.ts; the withdrawn /retreats/bali-may address 301-redirects to /retreats/bali — why: one source of content, and a new departure only needs a route with its dates.
- Trip pages (Bali retreat, ski trip) share one editorial layout built from src/components/trip-layout.tsx (Eyebrow, sticky SectionNav, tickable PackingNote); each page reads its text and photos from src/lib/*-content.ts — why: the trips look and navigate alike while each keeps a single source of content.
- Trip schedules render as a DayTimeline day picker fed by getDayTimeline (Bali) and getSkiDayTimeline (ski) over the schedule data in src/lib — why: the host's schedules stay the single source of truth while the layout changes.
- The Huella community (benefits for anyone who has travelled with us) lives in src/lib/community.ts and renders as a full homepage section plus a teaser on each trip page — why: one list of real benefits, reused wherever it helps sell a trip.
